# Domain Data Model v0.1

This document defines domain entities, not final database tables.

Persistence design will follow module ownership rules.

## Relationship Principle

Priority is **not** a permanent Factory attribute.

It is derived in context:

```text
Factory
+ Recovery Application
+ Funding Programme
+ Portfolio Strategy
→ Assessment / Candidate
```

The same factory can be highly prioritized in one programme and ineligible in another.
